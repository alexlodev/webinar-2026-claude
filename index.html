El punto de partida

¿Qué es Claude?

🧠

Modelo de lenguaje

Desarrollado por Anthropic. Diseñado para ser útil, seguro y honesto en conversaciones y tareas complejas.

💬

Asistente de chat

Accesible vía claude.ai o API. Responde preguntas, escribe, analiza y razona — todo desde el navegador.

🔑

Base de todo

Claude Haiku, Sonnet y Opus son los modelos. Claude Code los usa internamente para potenciar el desarrollo.

🌐

200K tokens

Ventana de contexto enorme. Puede procesar libros, codebases completos y conversaciones largas en un solo pase.

La diferencia clave

Claude vs Claude Code

Claude (chat)
  • Conversación en el navegador
  • Sin acceso al sistema de archivos
  • Sin contexto del proyecto
  • Sin ejecución de comandos
  • Respuestas de texto
vs
Claude Code (CLI)
  • Vive en tu terminal
  • Lee, escribe y navega archivos
  • Entiende tu codebase completo
  • Ejecuta comandos del sistema
  • Acciones concretas en el repo

Modos avanzados

Planning vs Thinking

Planning Mode

Planificar primero

Antes de escribir código, Claude presenta un plan paso a paso. Podés revisar, aprobar o ajustar la estrategia antes de que empiece a ejecutar.

Ideal para: features nuevas, refactors grandes, decisiones arquitectónicas
Thinking Mode

Razonamiento profundo

Claude "piensa en voz alta" antes de responder — explora pros, contras y casos borde internamente antes de darte una respuesta.

Ideal para: bugs difíciles, preguntas complejas, trade-offs técnicos
Extensiones de comportamiento

¿Qué son los Skills?

/commit

Commit inteligente

Analiza los cambios staged y genera un mensaje de commit semántico con contexto real del diff.

/review-pr

Code review

Revisa un PR completo: lógica, seguridad, estilo y posibles bugs. Devuelve un reporte estructurado.

/pdf · /docx · /xlsx

Generación de documentos

Crea PDFs, Word o Excel desde el contenido del proyecto con un solo comando.

/claude-api

Integración con API

Scaffolding automático para apps que consumen la API de Anthropic con prompt caching incluido.

/schedule

Tareas programadas

Crea agentes remotos que corren en cron. Claude ejecuta tareas periódicas sin intervención manual.

/skill-creator

Crear tus propios skills

Podés definir skills personalizados para tu equipo: flujos repetitivos convertidos en comandos.

Por dentro

Skills — Cómo funcionan y sus límites

⌨️

Invocás el skill

Escribís /commit en el chat de Claude Code

→
📄

Se inyecta en el contexto

El skill se expande a un prompt especializado que entra en la ventana de contexto

→
⚙️

Claude ejecuta

El modelo corre con ese contexto enriquecido y realiza las acciones del skill

📊

Consumen tokens

Cada skill agrega ~500–2,000 tokens al contexto. En sesiones largas esto se acumula.

🔁

Son secuenciales por defecto

Un skill corre a la vez en la misma sesión. Para paralelismo real se necesitan agentes.

🧠

Limitados por el modelo base

Un skill no puede hacer lo que Claude no sabe hacer. Son prompts, no código arbitrario.

🔒

No modifican el comportamiento core

Los límites de seguridad y políticas de Anthropic siguen aplicando sin excepción.

Escalar más allá de un solo chat

Multi-Agentes

¿Por qué no solo en el prompt?

Un solo contexto

  • 200K tokens se llena en tareas grandes
  • Todo en uno = Claude pierde foco
  • No hay paralelismo real
  • Un error contamina toda la conversación
  • Difícil de auditar y depurar

Con multi-agentes

Contextos especializados

  • Cada agente tiene su propia ventana de 200K
  • Trabajan en paralelo, reduciendo tiempo total
  • Cada uno es experto en su subtarea
  • Fallos aislados, fácil de reintentar
  • Orquestador coordina resultados

¿Cuánto consume cada elemento?

System prompt Instrucciones base del operador o plataforma. Fijo por sesión, no varía.

CLAUDE.md Contexto persistente del proyecto. Más detallado = más tokens, mantenerlo conciso.

¿Cómo monitorear el uso?

💬
Indicador en el chat
Claude Code muestra tokens usados / disponibles en tiempo real en la barra de estado.
📊
Comando /cost
Muestra el costo estimado y tokens consumidos en la sesión actual.
🔄
Compact & /clear
Claude comprime automáticamente el historial. /clear resetea el contexto si se satura.
Regla práctica: Usá subagentes cuando una tarea requiera más de ~50K tokens de contexto o cuando quieras correr subtareas en paralelo. Los skills son baratos; el historial largo es el mayor consumidor.
